侵权下架通道

最后更新：2026-10-13

先说明一件事

本站不托管、不存储、不分发任何软件文件，页面上的链接均指向软件官方来源或代码托管平台。因此这里通常不涉及「删除文件」的诉求；如果你要处理的是第三方站点上的侵权文件，需要联系该站点的服务商。

本站能做的、也会做的是：下架对应条目（移除介绍文字、图标与跳转链接）。

怎么提交

请通过 GitHub Issues 提交下架申请，并在内容里写清：

  • 涉及的条目名称或页面地址（例如 /tool/xxx.html）
  • 你的身份与权利依据（著作权人本人、授权代理人，或商标/名称权权利人，并附简要说明或凭证链接）
  • 你的诉求（下架条目 / 修改描述 / 更换链接）
  • 可接收回复的联系方式

公开 Issue 里请勿提交身份证件、合同等敏感材料原图，可只说明权利类型，必要时再约定其他渠道核验。

处理时限

收到申请后3 个工作日内核实并答复。经核实的有效申请会立即下架对应条目并重新构建站点（约 1 分钟生效）。对内容有争议的，站长倾向先下架再沟通。

内容纠错

如果只是信息过时、链接失效、描述有误，同样欢迎走上面的渠道反馈，这类问题通常当天处理。
