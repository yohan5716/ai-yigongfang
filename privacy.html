隐私政策

最后更新：2026-10-12

一句话概括

本站是纯静态站点，没有账号系统，不收集你的姓名、手机号、邮箱等任何身份信息，不使用 Cookie，不投放广告，不接入任何第三方统计或分析脚本。

保存在你浏览器本地的数据

以下数据只存在你自己的浏览器 localStorage 里，不会上传到服务器，清空浏览器数据即全部消失：

  • aiygf:theme — 你选择的明暗主题
  • aiygf:favs — 你收藏的工具条目
  • aiygf:liked / aiygf:likeDelta — 你点过赞的条目与本地待同步增量

站长后台页（/admin.html）另会把仓库地址与访问令牌存在你本机浏览器里，同样不会上传到第三方。

点赞接口会处理什么

为了防止刷赞，点赞接口在启用时会把访问者的 IP 与 User-Agent 拼起来做一次 SHA-256 摘要，取前 16 位十六进制字符作为去重指纹，24 小时后自动过期。原始 IP 不会被存储。

需要说明的是：本站当前部署在 GitHub Pages 上，该接口并未运行，因此现阶段点赞数据完全保存在你的浏览器本地。

托管平台产生的日志

本站由 GitHub Pages 托管，GitHub 可能按其一贯做法记录访问 IP 与 User-Agent 等常规访问日志。这部分数据处理遵循 GitHub 自身的隐私声明，本站无法访问也无法控制。

第三方资源

站内不加载任何第三方 CDN、外部字体或统计脚本。页面用到的图标是 emoji 或内联 SVG，二维码生成组件 vendor/qrcode.js 由本站自行托管。

未成年人

本站不面向未成年人收集任何信息，事实上也不向任何人收集身份信息。

政策变更与联系方式

本政策如有调整会在本页更新。对隐私处理有疑问，可通过 GitHub Issues 提出。
